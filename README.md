# Simple Website Template

A clean, modern, and responsive website built using standard HTML5, CSS3, and JavaScript.

## 🚀 How to Open and View
1. Open the folder `simple-website` on your Desktop.
2. Double-click **`index.html`** to view the website directly in any web browser (Chrome, Edge, Firefox, etc.).

## 📁 Files Included
- **`index.html`**: Contains the page structure, navigation, hero banner, about cards, services, contact form, and footer.
- **`style.css`**: Provides modern styling, responsive layouts, hover animations, and dark/light mode themes.
- **`script.js`**: Controls interactive features including the light/dark theme toggle and the like counter button.

## ✏️ How to Customize
- **Change Text & Titles**: Open `index.html` in any code editor (like VS Code or Notepad) and update the text between the HTML tags.
- **Change Colors & Fonts**: Open `style.css` and adjust the variables under `:root` (e.g. `--primary: #4f46e5;`).
- **Add New Sections**: Duplicate any `<section>` block in `index.html` and customize the content.
